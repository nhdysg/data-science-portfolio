# Data provenance

| File | Contents | Source |
|---|---|---|
| `raw/hot100.parquet` | Billboard Hot 100, every week from 1958-08-04 to 2026-10-17 (355,900 rows) | `data-out/hot-100-current.csv` from [utdata/rwd-billboard-data](https://github.com/utdata/rwd-billboard-data) |
| `raw/billboard200.parquet` | Billboard 200, every week from 1967-04-15 to 2026-10-17 (620,891 rows) | `data-out/billboard-200-current.csv` from the same repository |
| `kpop_artists.csv` | Hand-curated list of K-pop credited names, act family, segment, and the date from which a name counts as K-pop | Compiled for this project |

The two CSVs were downloaded on 2026-10-13 and converted to Parquet (zstd) without other changes.
SHA-256 of the downloaded CSVs:

- `hot-100-current.csv`: `3f2a274dd7cb26217c3bce8fb2e761ed3e131c5da6c00744a39c070e8b47dc20`
- `billboard-200-current.csv`: `a22e2ef47e3bb8e27111bca7f824f2dcd06d1627bbf508bcbcfe147803154380`

Columns: `chart_week`, `current_week` (position), `title`, `performer`, `last_week`, `peak_pos`, `wks_on_chart`, `wks_at_no1`.
Chart data © Billboard; the compiled files are shared by the UT Austin School of Journalism for teaching and research.

`processed/` is generated by `python build.py` and committed so the R analysis can run on its own.
